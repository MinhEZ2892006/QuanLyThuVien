
# 📚 Library Management System

### A Modern Library Management Web Application

A web-based Library Management System developed using ASP.NET Core MVC and C#. This application helps librarians efficiently manage books, members, and borrowing activities through a user-friendly interface.

---

## 🚀 Features

- 📖 Book Management: Add, edit, delete, and search books.
- 👥 Member Management: Manage library members.
- 📋 Borrowing Management: Track book borrowing and returns.
- 🔍 Search System: Quickly find books and information.
- 🔐 User Authentication: Secure access to the system.
- 📊 Dashboard: Monitor library activities.

## 🛠️ Technologies Used

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML5 / CSS3
- JavaScript
- Bootstrap

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/MinhEZ2892006/QuanLyThuVien.git
```

2. Open the project using Visual Studio.

3. Configure your database connection in `appsettings.json`.

4. Apply database migrations if required.

5. Run the application.
